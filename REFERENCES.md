# 공식 참고 자료

튜토리얼의 UI 용어와 배포 방식은 아래 공식 자료를 기준으로 확인했습니다.

- [Reality Composer Pro](https://developer.apple.com/documentation/realitycomposerpro)
- [Creating particle systems in Reality Composer Pro](https://developer.apple.com/documentation/realitycomposerpro/creating-particle-systems-in-reality-composer-pro)
- [Reality Composer Pro Beta 4 Release Notes](https://developer.apple.com/documentation/realitycomposerpro/reality-composer-pro-beta-4-release-notes)
- [Creating animation sequences](https://developer.apple.com/documentation/realitycomposerpro/creating-animation-sequences)
- [Meet Reality Composer Pro — WWDC23](https://developer.apple.com/videos/play/wwdc2023/10083/)
- [Swift-DocC](https://github.com/swiftlang/swift-docc)
- [Using custom workflows with GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

Reality Composer Pro 3의 베타 UI는 릴리스에 따라 일부 메뉴 위치나 명칭이 달라질 수 있습니다. 실제 스크린샷을 촬영할 때 현재 설치된 버전과 튜토리얼 문장을 대조하고, 차이가 있다면 영문 UI 명칭만 해당 버전에 맞게 수정하세요.
